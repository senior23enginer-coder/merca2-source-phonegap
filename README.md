# Merca2 · frontend PhoneGap

Frontend móvil histórico de Merca2 con HTML, CSS, JavaScript y recursos cliente para PhoneGap y Cordova.

<!-- station-x-repository-guide:start -->

## Guía de esta copia

### Mapa del contenido
[index.html](./index.html) es la entrada web. [js](./js), [css](./css) e [img](./img) contienen el frontend, y [res](./res) reúne recursos móviles. [cordova.js](./cordova.js), [cordova_plugins.js](./cordova_plugins.js) y [phonegap.js](./phonegap.js) corresponden a la integración con el contenedor híbrido.
### Preparación
Para revisar la interfaz, sirve los recursos desde un entorno local. Las funciones nativas dependen de la plataforma, de las versiones de Cordova y de los plugins del proyecto original. Recupera esa configuración del ambiente correspondiente antes de empaquetar.
### Verificación
Comprueba navegación, carga de recursos y flujos que usen plugins en el contenedor móvil de prueba.
